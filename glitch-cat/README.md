## 🏛️ Invariants & Principles
- **Kem's Law:** *"A skill is instructions the model may follow; a hook is code that ALWAYS runs."*
- **Context Rot Shield:** Never slurp entire files or greps into LLM context; use `cgate` AST slicing and local-LLM query projection.
- **Fresh-Context Judges:** Subagent work is evaluated by an unbiased judge in a fresh context window before merging.

## 🎛️ Host Harness Adapters (`harnesses/`)

Kem doctrine is designed to hook cleanly into whatever harness hosts the agent. Detailed adapters live in [`harnesses/`](./harnesses/):
- **T3 Code** ([`t3-code.md`](./harnesses/t3-code.md)): ACP delegate orchestration, `isolation: "worktree"`, preview tools, reactive wakeups, HTML visuals (`html_preview` + `html_render`).
- **Gemini / Antigravity CLI** ([`gemini-antigravity.md`](./harnesses/gemini-antigravity.md)): Native Python `run_workflow` graphs, dynamic subagents (`define_subagent`), `Workspace: "branch"`, surgical diffs (`replace_file_content`).
- **OpenCode** ([`opencode.md`](./harnesses/opencode.md)): Local daemons (`:8080`, `:8083`), compound bash batching, git worktrees (`worktree-harness`), disk JSON ledgers (`step_NN.json`).
- **Claude Code** ([`claude-code.md`](./harnesses/claude-code.md)): `.claude/hooks/` pre-execution guards, `CLAUDE.md` 200-line budget, `Agent` subagents.
- **Pi Agent & Boxxy Claw** ([`pi-boxxy.md`](./harnesses/pi-boxxy.md)): Hot-reloaded skills, direct CLI tooling, local GPU ports.

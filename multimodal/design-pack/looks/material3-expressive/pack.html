Style Sheet

Production constraint · 8-section spec · measured contrast

Production constraint: Tonal-surface elevation + spring-physics spatial feedback

NEVER block · 7 bans
  • NEVER use unlayered raw hover hexes — state layers mix --md-on-* ink at 8% hover, 10% focus, 12% press.
  • NEVER box every card in 1px grey borders — stack the 5 tonal container tiers instead.
  • NEVER use pure black grounds or pure black shadows — Dark mode rests on #141218 (#0f0d13 lowest).
  • NEVER apply spatial overshoot to color or opacity — effects curves stay critically damped (0% overshoot).
  • NEVER use arbitrary easing keywords or stepped animations — use only the 6 declared spring tokens.
  • NEVER place multiple Filled CTAs or FABs in one screen region — preserve the 5-level emphasis ladder.
  • NEVER use --md-outline or --md-outline-variant as readable body text ink.

8 · Texture & Motion

8-step shape ladder (4px–9999px), ambient + key shadows, 3 Spatial overshoot springs (350/500/650ms) + 3 Effects springs (150/200/300ms).

Do / Don't — Drawn Comparisons

Same subject side-by-side · structural rationale
DO · Tonal Surface Ladder Step container values
Outer surface container
Inner elevated group without heavy strokes

Tonal value contrast defines hierarchy cleanly across Light and Dark without visual clutter.

DON'T · Grey Border Boxes Flat wireframe cages
Outer bordered panel
Nested 1px grey box at identical luminance

Grey border boxes flatten elevation and turn dense dashboards into noisy wireframes.

DO · Single Filled CTA + Tonal Siblings Clear primary focus

One Filled CTA anchors attention; Tonal and Text actions step gracefully downward.

DON'T · All-Primary Wall Competing emphasis
Publish Preview Cancel

Three simultaneous Filled buttons erase priority and create decision paralysis.

DO · State Layer + Pressed Shape Morph 9999px → 8px tactile snap
Rest Hover 8% Pressed 8px

Ink state-layer mixes combine with fast-spatial corner morphing to confirm touch.

DON'T · Static Hover No layer or corner feedback
Rest Hover Pressed

Identical static rectangles deny tactile feedback and ignore M3E shape language.

DO · Spatial Overshoot vs Damped Effects Geometry bounces · color settles
Spatial (Overshoot)

Shape, thumb slide, toolbar lift via --ease-spatial-fast.

Effects (0% overshoot)

Hover mix, fill fade, theme swap via --ease-effects-fast.

Separating spring geometry from critically damped opacity prevents flickering color overshoot.

DON'T · Overshoot on Effects Unpaired spring curves
Color & opacity animated with 1.67 overshoot or generic easing.

Bouncing opacity flashes above 1.0 or clips color transitions; un-declared easing drifts off-pack.

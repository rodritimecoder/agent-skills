## Top 5 cross-cutting fixes (ranked, with exact file:line and the minimal change)

1. **Give `guard-hooks` a machine-readable contract (P9 + P10, the only hard blocker for Code Mode).** Evidence: `glitch-cat/guard-hooks/guard_hooks.py:5-8` execs the compiled Rust binary; `glitch-cat/guard-hooks/guard-rs/src/main.rs:265` (`#[derive(Parser)] struct Cli`) has no `--json`/`--omni-schema`/`--limit`; code-mode verifier output: `deferred — "--json needs a Rust change and a rebuild"`. Minimal change: add `--json`, `--omni-schema`, and `--limit` to the clap `Cli`, emit `serde_json` for `check`/`check-file` on clean stdout (keep the 🛑 message on stderr), then rebuild `bin/guard-hooks`. Highest impact because it is the one skill whose primary path cannot be introspected at all.

2. **Fix description triggers and the hard length cap (P2 — 5 skills).** Evidence: `glitch-cat/{agentic-engineering,eval-pipeline,glitch-orchestra,graph-memory}/SKILL.md:4-8` have no `Use when`/`Use for`/`Load when` clause (passive, noun-first); `glitch-cat/jev-decision/SKILL.md:4-17` is 1095 chars (verifier `description-length` ERROR, cap 1024). Minimal change: append one imperative `Use when <intent>...` sentence to each of the four; delete the two longest `box` examples from jev-decision's `description` to drop below 1024. Also repair the truncated "workflow from." at `glitch-orchestra/SKILL.md:6`.

3. **Move helper/test modules out of `scripts/` (P5 — 5 skills).** Evidence: `glitch-cat/agentic-engineering/scripts/test_agentic.py`; import-only helpers `glitch-cat/eval-pipeline/scripts/pipeline_core.py`, `glitch-cat/eval-router/scripts/classifier.py` (0755 + verifier `script-no-help`), `glitch-cat/glitch-orchestra/scripts/orchestra_conductor.py`, `glitch-cat/jev-decision/scripts/jev_engine.py`. Minimal change: `git mv` helpers to `modules/` and the test to `tests/`; for `classifier.py` at minimum drop the exec bit/shebang so omnicli stops cataloging it as a CLI.

4. **Replace absolute/deep file references with skill-root-relative ones (P4 — 4 skills).** Evidence: `glitch-cat/eval-pipeline/SKILL.md:49`, `glitch-cat/eval-router/SKILL.md:66,84,94`, `glitch-cat/glitch-orchestra/SKILL.md:44`, `glitch-cat/graph-memory/SKILL.md:56` (`/run/media/rodri/AI/skills/...`), plus the `../../orchestration/...` link at `glitch-cat/eval-router/SKILL.md:143`. Minimal change: write CLI examples as `python3 scripts/<entry>.py` ("run from skill root", as frontend-uat/jev-decision already do at `frontend-uat/SKILL.md:49-52` and `jev-decision/SKILL.md:54-57`); replace the `../../` link with a plain-text "see the `gh-action-subagent` skill" pointer discoverable via `omnicli describe`.

5. **Bound list output and add structured output to the laggards (P9/P10 — 3 skills).** Evidence: code-mode `b2b` violations on `eval-pipeline` (`eval_pipeline.py:100-111` prints every step) and `glitch-orchestra` (no `--fields/--project` on `status`); verifier `script-no-json` on `apiv-loop/scripts/apiv_loop.py`. Minimal change: add `--project/--fields` + `--limit N` (or `--out`) to `eval-pipeline audit` and `glitch-orchestra status`; add a global `--json` that emits one object to stdout with progress on stderr to `apiv-loop`. `graph-memory` (`:53,64-66`) and `frontend-uat` (`:524-551`) are the in-batch models to copy.

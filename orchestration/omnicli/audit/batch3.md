## Top 5 cross-cutting fixes (ranked, with exact file:line and the minimal change)

1. **Add `--dry-run` to every stateful CLI (point 10 — 10/10 skills FAIL).** Nothing in the batch implements it (repo-wide grep for `--dry-run` across all `*.py`/`*.js` returns zero hits). Minimal: in each mutating subparser add `p.add_argument("--dry-run", action="store_true")` and guard the write/mutate/merge call — start with `worktree-harness/scripts/harness.py:591` (`integrate`), `:603` (`teardown`), `state-compactor/scripts/compactor.py` (`record`/`wrap`/`compact`), `swarm-contract/swarm_contract.py:14` (`check`/`record`), `verification/scripts/verify.py:857` (`control`), `parallel-test-lane/scripts/test_lane.py:202` (`run`). Highest leverage: this is the single reason no skill scores full exec-readiness.
2. **Move helper modules (and one doc) out of `scripts/` (point 5 — 6 skills FAIL).** Exact offenders: `notes-index/scripts/notes_index_core.py:1` (executable 775, no `__main__`), `projects-harness/scripts/harness_core.py:1`, `semantic-cache/scripts/cache_engine.py:1`, `swarm-contract/scripts/swarm_engine.py:1`, `verification/scripts/{cdp_lite,verify_common,verify_control,verify_forge}.py:1`, `reply-meter/scripts/card.md:1` (Markdown → `references/`). Minimal: `mkdir -p modules && git mv scripts/<helper>.py modules/`; note `verification/scripts/cdp_lite.py` is 775 with no `__main__` so `omnicli` may index it as a phantom tool. (Minor: `memory/_tools/test_capture.mjs` belongs in `tests/`.)
3. **Give the shipped `cgate` a typed contract and `--json` (points 6 + 9 — state-compactor).** `state-compactor/bin/cgate` (clap/Rust) rejects both: `cgate --omni-schema` → exit 2, `cgate grep --json` → exit 2 (probed). Minimal: implement `--omni-schema` printing an MCP JSON Schema and a `--json` flag in `cgate-rs/src`, OR make `scripts/cgate.py` the omnicli entrypoint and keep the binary as an operator convenience. As-is, the skill's primary documented reader cannot be driven from Code Mode with structured output.
4. **Restore global `--json` on CLIs that only expose it on one subcommand (point 9 — 3 skills FAIL).** `parallel-test-lane/scripts/test_lane.py:199-208` has no `--json` at all (JSON only written to `--out` at L173); `state-compactor/scripts/compactor.py:365,374` only on `check`/`inspect`; `worktree-harness/scripts/harness.py:600` only on `status`. Minimal: add `--json` to the shared `parents=[common]` parser (the `notes-index/notes_index.py:42` / `verification/scripts/verify.py:785-787` pattern) and gate the human `print()` calls behind `if not args.json`.
5. **Add intent-first "Use when…" triggers to 4 passive descriptions (point 2 — 4 skills FAIL).** `parallel-test-lane/SKILL.md:4-8`, `projects-harness/SKILL.md:4-9`, `reply-meter/SKILL.md:4-11`, `swarm-contract/SKILL.md:4-8` describe *what* but never *when* and open in passive third person (the glitch-cat `AGENTS.md` §Provenance explicitly wants routing text, not club/reel lore — all four keep reel ids in the body, which is correct). Minimal: prepend one `Use when …` sentence naming user intent to each folded description; no need to rewrite the rest.

Honorable mention (not in top 5): six SKILL.md quickstarts hardcode `/run/media/rodri/AI/skills/<skill>/…` or `$HOME/...` instead of the installed command (`notes-index/SKILL.md:51`, `parallel-test-lane/SKILL.md:39`, `projects-harness/SKILL.md:87`, `semantic-cache/SKILL.md:34`, `swarm-contract/SKILL.md:26`, `reply-meter/SKILL.md:114,165`).
